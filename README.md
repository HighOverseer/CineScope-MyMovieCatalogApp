# CineScope : MyMovieCatalogApp

---

## How to Run

1. Clone the project from GitHub:
   ```
   git clone https://github.com/HighOverseer/CineScope-MyMovieCatalogApp.git
   ```
2. Open the project in Android Studio.
3. Add API Access Token of your account registered in https://developer.themoviedb.org/docs to your `local.properties` file like this:
   ```
   API_ACCESS_TOKEN=YOUR_API_ACCESS_TOKEN
   ```
4. Wait for Gradle Sync to finish.
5. Run the project on an emulator or physical device.
